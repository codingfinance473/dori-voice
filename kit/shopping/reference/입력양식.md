# 입력 양식 — 사용자에게 받을 것

## 웹 조사 편(기본) — 주제만 주면 된다

```
[주제] 유니클로 겨울템 / 일본 드럭스토어 선크림 / 오사카 먹킷리스트 …
[나라·도시] 일본(오사카)
[원하는 품목] 있으면 적기(없으면 Claude가 인기·대표 품목을 골라 제안)
[태그] 유튜브 쇼핑 태그를 걸 편인지(걸면 한국 가격은 제휴처 기준)
```

- Claude가 브라우저로 공식몰 가격을 기계로 읽어 증거를 남기고(화면+서버 원본), 한국은행 ECOS 매매기준율을 받아, 대조표·증거표(품목·상품번호·두 나라 가격·읽은 방식·확인 시각·주소)를 먼저 보여 준다.
- 브라우저로 증거를 남길 수 없는 가격은 쓰지 않는다(캡처로 받은 숫자는 `verify: "draft"` 연습용이거나 영수증 편으로만).
- 영상은 증거 확인 후 24시간 안에 올린다. 늦어지면 다시 읽는다.
- 직접 찍은 사진·영상이 있으면 같이 주면 좋다(그림 대신 쓰고, 화면에 '직접 찍은 사진'으로 표시된다).

## 영수증 편 — 여행에서 실제로 산 경우

```
[여행] 도시: 오사카 / 가게: 드럭 스토어(○○점) / 결제일: 2026-09-14 / 통화: 엔
[영수증] 사진 첨부 (없으면 품목별 금액을 아래에)
[카드] 원화 결제액: 26,480원 (카드 앱 알림·명세 캡처 첨부하면 더 좋음)
[품목]
1. 쿨링 시트 18매 / 598엔(면세가) / 사진 a.jpg / "발바닥에 붙이면 시원함"
2. 녹차 초콜릿 과자 12개입 / 648엔 / 영상 d.mp4 / "선물용으로 반응 좋았음"
[한국가] 알고 있으면 적기(판매처·가격·확인일). 모르면 Claude가 찾고, 확인 안 되는 건 물어본다
```

- 금액·용량이 없는 품목은 영상에 넣지 않는다(숫자를 추정하지 않는다).
- 메모는 실제로 느낀 그대로 짧게. 대사에서 "~래"로 인용된다. 효과·효능 대신 느낌으로.
- 의약품·의약외품(안약, 진통 파스, 영양제)은 다루지 않는다.
