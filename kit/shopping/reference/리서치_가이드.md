# 가격 리서치 가이드 (웹 데이터 편, 3판)

영수증 없이 공개된 가격만으로 한 편을 만든다. 숫자는 공식 출처에서 **기계로 읽은 증거 기록**으로만 가져오고,
모든 가격에 출처 주소와 확인 시각(한국 시간)을 남긴다. 사람이 화면을 보고 숫자를 옮겨 적지 않는다.

## 1. 원칙

- 추정하지 않는다. 증거로 확인되지 않는 가격은 그 품목을 뺀다(`kr: null` = 현지에서만은 한국 판매처가 없음을 확인하고 `evidence.py absent` 로 남겼을 때만).
- 같은 상품끼리 비교한다: 상품번호·용량·구성(1+1, 세트, 리뉴얼판)을 맞춘다. 용량이 다르면 `size` 로 환산하고, 구성이 다르면 뺀다.
- 가격 기준을 한 편 안에서 통일한다: 현지·한국 모두 세금 포함 정가(할인·쿠폰 제외). 한국 제휴처 가격이면 배송비 포함.
- 한 가격마다 **읽는 방식이 다른 기록 2개 이상**이 같아야 한다(화면 + 서버 원본, + 검색 목록). 하나라도 다르면 멈추고 원인(색·사이즈·할인·다른 상품)을 찾는다.
- 할인 표시가 하나라도 보이면 정가 비교에서 멈춘다. 전 품목 기간 한정가를 쓰려면 품목에 `allow_sale: true` 와 기간을 적고 할인가로 다시 읽는다(화면·설명에 "기간 한정가, ~까지").
- 증거는 마지막 확인 후 24시간까지만 쓴다(`max_age_h`). 렌더·업로드가 늦어지면 다시 읽는다.
- 의약품·의약외품(안약, 진통 파스, 영양제 등)은 다루지 않는다. 효능 비교가 아니라 가격 비교라도 광고 규제·의학 조언 금지(음성 모델 라이선스) 문제가 생긴다.

## 2. 데이터별 출처

| 데이터 | 쓰는 것 | 쓰지 않는 것 | 기록 |
|---|---|---|---|
| 현지 가격 | 브랜드 공식몰(같은 상품번호) 화면 + 서버 원본 | 블로그·기사·가격 비교 사이트 | `capture.js` product·state·list |
| 한국 가격 | 브랜드 한국 공식몰, 유튜브 쇼핑 제휴처 | 중고·병행 수입·해외 직구 | 같은 방법 |
| 환율 | 한국은행 ECOS 731Y001(서울외국환중개 매매기준율) | 기사 속 마감 환율, 포털 실시간 환율 | `evidence.py fx` |
| 제도·규칙 | 정부 기관 원문(예: 일본 관광청) | 여행 블로그 | `capture.js` quote → `literals` |
| 인기·순위 | 매장·기관이 낸 순위·통계 | "다들 사 오는" 같은 근거 없는 말 | 출처 주소 |

환율 메모: ECOS 의 날짜 값은 그날 아침 고시된 매매기준율이다(주말·공휴일은 직전 영업일 값). 같은 날 장 마감 환율(기사)과 다를 수 있으니 섞지 않는다.

## 3. 브라우저로 증거 읽기 (Claude in Chrome 등)

1. 상품 페이지를 연다(새 탭). 쿠키 동의 창은 누르지 않거나 필수만 허용.
2. `assets/capture.js` 내용 + 호출 한 줄을 javascript 도구로 실행한다. **실행 한 번에 기록 하나**(도구 출력이 길면 잘려 서명이 사라진다).
   ```js
   await DoriCapture.product({item:'a', side:'local', code:'E461003', currency:'JPY'})   // 화면 가격
   await DoriCapture.state({item:'a', side:'local', code:'E461003', currency:'JPY'})     // 같은 주소를 다시 받아 서버 원본(정가·할인가·세금 포함 여부)
   await DoriCapture.list({item:'a', side:'local', code:'E461003', currency:'JPY'})      // 검색 결과 페이지에서
   await DoriCapture.quote({id:'tax', needles:['2026年11月1日購入分から', '90日以内', '5,000円以上']})   // 제도 원문(한 기록에 문구 3개까지)
   ```
   같은 페이지에서 두 번째 호출은 라이브러리를 다시 넣지 않고 호출 줄만 실행해도 된다.
3. 나온 문자열을 **한 글자도 고치지 말고** `evidence/inbox.jsonl` 에 한 줄씩 붙인다 → `evidence.py add` 가 서명을 다시 계산해 바뀐 기록은 받지 않는다.
4. 페이지 사이 4~5초 쉰다. 짧은 시간에 많이 열면 사이트가 막는다(2026-10-24 유니클로 한국 검색이 16번째쯤 "Access Denied"). 막히면 그 사이트는 멈추고, 이미 2가지 방식이 있으면 그대로 간다.

사이트별 메모(2026-10 확인):
- **유니클로**: 일본 `uniqlo.com/jp/ja/products/E{번호}-000/00`, 한국 `uniqlo.com/kr/ko/products/E{번호}-000/00` 가 같은 상품이다. 화면 가격 `.fr-ec-price-text--large`. 서버 원본은 HTML 의 `__PRELOADED_STATE__` 안 `prices.base.value`(정가)·`prices.promo`(할인가, 없으면 null)·`taxPolicy`(INCLUSIVE)·`flags.priceFlags`(가격 표시 플래그). 일본 검색(`/search?q=번호`)은 상품에 따라 결과가 없을 수 있다(라운드 미니 숄더백 E481610 은 없음) → product + state 로 충분하다.
- **크롬 자동 번역**: 사용자 크롬이 일본어 페이지를 한국어로 번역해 보여 줄 수 있다. 화면 기록(product·list)은 번역된 글자를 읽으므로, 번역의 영향을 받지 않는 state·quote 와 값이 같아야 통과한다.
- **공식몰 상품 페이지는 대부분 화면을 자바스크립트로 그려** WebFetch·작업 공간 셸로는 가격이 안 나온다(셸은 네트워크 허용 목록 밖이라 접속 자체가 막힌다).
- **금융 정보 사이트**(네이버 금융 등)는 브라우저 확장에서 막힌다 → 환율은 ECOS API 로만.
- **쿠팡**은 자동 접속을 막는 경우가 많다 → 다른 제휴처나 사용자가 직접 연 화면에서 capture.js.
- 브라우저가 없을 때는 웹 조사 편을 만들지 않는다(증거를 남길 수 없다). 사용자 캡처로 만들면 `verify: "draft"` 로 연습만 하거나 영수증 편으로 만든다.

## 4. 넣고 검사하기

```bash
python3 "$SK/scripts/evidence.py" add   <폴더> <폴더>/evidence/inbox.jsonl
python3 "$SK/scripts/evidence.py" fx    <폴더>              # ECOS 매매기준율 (키는 SKILL.md '키')
python3 "$SK/scripts/evidence.py" check <폴더>              # 통과 → evidence/verified.json
python3 "$SK/scripts/evidence.py" show  <폴더>              # 무엇이 들어 있나
```

검사 규칙은 `evidence.py` 맨 위 설명(서명, 방식 2가지, 값 일치, 상품번호, 할인, 통화·세금, 24시간, 환율 신선도, episode 값 대조, 제도 원문).
calc.py·render.py(video)·qa.py 가 같은 검사를 다시 돌린다 — 증거가 만료되거나 계산 뒤 바뀌면 그 단계에서 멈춘다.

## 5. 세금·면세 (일본, 2026-11-01부터)

일본 관광청 원문([여행자용 안내](https://www.mlit.go.jp/kankocho/tax-free/page01_000001_00021.html), 2026-10-24 01:52 원문 확인):
- 「2026年11月1日購入分から」 면세점에서도 세금 포함 가격으로 결제하고, 출국 때 세관이 반출을 확인한 뒤 소비세 상당액을 돌려받는다(리펀드 방식).
- 「購入日から90日以内に」 출국하며 키오스크·전자 단말에 여권을 제시해 세관 확인을 받아야 한다.
- 「同一店舗における1日の購入額（税抜）が5,000円以上」이 대상.

- 「免税店にて税込価格(課税)で免税対象物品を購入」, 「出国時の持出し確認後に消費税相当額が返金」 — 화면의 "계산은 세금 포함 가격으로", "출국할 때 세관 확인 뒤 소비세를 돌려받아요"의 원문(literals 의 tax_claims).
- 이 페이지에는 환급 수수료 언급이 없다 → 화면에 수수료 얘기를 쓰지 않는다(원문에 없는 말은 쓰지 않는다).

영상에서는 세금 포함 가격으로 판정하고, 환급은 합계 화면에 "같은 날 한 가게에서 다 사면 면세 대상 · 출국 때 세관 확인 뒤 소비세 상당액 약 ¥…(약 ₩…)을 돌려받아요"로만 보탠다
(`local_rule.tax_rate`·`refund_min_pretax`·`summary.refund`). 영수증의 소비세는 가게 끝수 처리에 따라 1엔쯤 달라지고 환급 수수료도 있어 "약"을 붙인다.
세전 합계가 기준과 아주 가까우면(경계값) calc.py 가 경고하고 화면에서 환급 줄을 뺀다.

## 6. 유튜브 쇼핑 태그

- 태그는 유튜브 쇼핑 제휴처 상품에만 걸 수 있다. 국내 제휴처(2026-10 기준 보도·유튜브 블로그): 쿠팡, 올리브영, 지그재그, 에이블리, 4910, CJ온스타일, 컬리, 퀸잇, 오늘의집, 알리익스프레스, W컨셉, 롯데홈쇼핑·GS샵·현대홈쇼핑.
- 자격: 유튜브 파트너 프로그램 가입 + 구독자 500명 이상.
- 태그를 거는 편만 광고 표시(화면 첫 2.6초 띠 + 작은 칩 + 제목 앞 [광고] + 설명 첫 줄). 태그가 없는 편(예: 유니클로 공식몰 비교)은 광고 표시를 하지 않는다.
- 태그 상품은 영상 속 품목과 같은 제품·용량이어야 한다. 한국 가격 출처가 공식몰인데 태그는 쿠팡이면, 쿠팡 가격도 증거로 읽어 설명에 적는다.

## 7. 사용자에게 먼저 보여 줄 것

calc.py 가 만든 `facts.md` — 대조표(현지가·원화 정확값·한국가·차이·판정), 증거표(품목·쪽·값·읽은 방식·기록 수·확인 시각·주소),
환율 기록(고시일·받은 시각·교차 확인), 제도 숫자 원문. 이걸 보여 주고 제작에 들어간다.
