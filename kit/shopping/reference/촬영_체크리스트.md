# 여행 중 촬영 체크리스트 (영수증 편·직접 찍은 재료, 품목당 1분)

영상의 차별점은 "직접 산 증거"다. 아래만 챙기면 나머지는 자동이다.

## 계산대 앞뒤
- [ ] **영수증**: 받자마자 평평한 곳에서 전체가 나오게 한 장(흔들림 없이, 글자 읽히게). 면세 영수증이면 면세 금액이 보이게
- [ ] **카드 결제 알림** 캡처(원화 금액) — 환율 계산이 가장 정확해진다
- [ ] 영수증이 없으면 **가격표**를 품목과 같이 한 장

## 품목마다
- [ ] **5초 영상** 또는 사진 1장: 손에 들고 천천히 돌리기 / 진열대에서 집는 장면. 세로 촬영, 밝은 곳
- [ ] **용량·개수**가 보이게(18매, 12ml 등) — 한국가와 용량을 맞추는 데 쓴다
- [ ] **한 줄 메모**(음성 메모도 됨): 왜 샀는지, 써 보니 어땠는지, 다시 살지

## 돌아와서 (선택)
- [ ] 같은 제품 한국 판매가를 쿠팡·올리브영 앱에서 보고 캡처(판매처·가격·날짜)
- [ ] "다시는 안 산다" 싶은 물건이 있으면 꼭 메모 — 후회템은 신뢰를 올리는 반전이 된다

## 찍지 않는 것
- 다른 손님 얼굴, 직원 얼굴·명찰, 카드번호가 보이는 화면
- 매장 안 음악이 크게 들어간 소리(영상 소리는 쓰지 않지만 혹시 모를 저작권 시비 방지)
- 촬영 금지 표시가 있는 매장 내부
