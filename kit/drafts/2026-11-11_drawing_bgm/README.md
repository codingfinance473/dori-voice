# 그림체·배경음 고도화 시안 (2026-11-11) — 아직 채택 전

사용자 요청: "도리 쇼츠를 드로잉 스타일을 가미해서 고도화, 잘나가는 쇼츠 BGM을 참고해서 설명하는 박자에 맞게 은은하게".
시험 편: EX.09 수능 스마트안경(이미 올린 편 — 다시 올리지 않는다, 시안용으로만 다시 렌더).

## 그림체 — `sketch.js`
index.html 끝에 `<script>window.SKETCH={style:'A'}</script><script src="sketch.js"></script>`.
- 0 지금 그대로 · A 연필 스케치(흔들리는 선 + 초당 8번 선 끓임 + 겹선 + 캐릭터 오른쪽 아래 연필 음영) · B 색연필(A + 거친 색칠 결) · C 그림책 수채(번지는 물감 + 종이 결).
- 공통: 화면 전체 종이 결(곱하기), 벽 여백 연필 낙서(별·소용돌이·구름), 마루 연필 결. 글자(말풍선·자막·숫자)는 흔들림을 아주 작게.
- 결정적 렌더: 선 끓임은 render(t) 시각으로 정해진다. 렌더 시간은 프레임당 약 0.4초(필터) — 55초 영상 약 6분.

## 배경음 — `music.py` (mix.py 가 BED=P|L|M 일 때)
- 실제 악기 샘플(`fetch_sf.sh`)로 100 BPM: P 통통 피치카토 · L 로파이 피아노 · M 마림바 미니멀.
- 말 박자 맞춤: `BPM=100 python3 build_voice.py` — 줄 시작을 8분음표(0.3초) 격자에(쉼은 최대 0.22초 늘어남, 55초 편에 +0.8초).
- 멜로디는 말 틈에서만 대답(도리 뒤 높은 반짝 · 모리 뒤 낮은 능청), 모리 줄은 음악을 끄지 않고 낮은 옷으로 갈아입음, 장면 전환 올라가는 꾸밈, 숫자 단어 작은 화음, 검산 끝 으뜸화음, 쏙에 끝음.
- 크기: `BED_UNDER=13.5` — 말하는 동안 목소리보다 13.5dB 아래(은은하게). 받아쓰기: M 전부 통과, P L09 · L M00 한 줄씩 확인.

## 2차(2026-11-11 저녁) — 사용자 선택: 그림체 C · 배경음 1(피치카토) · 모리 '재치20대_중간'
- 사용자 의견: "C가 그나마 낫고, 배경음은 1번인데 뒤에 좀 이상해진다(중간까지 좋음)", "재치 20대 중간을 리액션 부분을 더 자연스럽게, 전반적으로 다듬어 달라".
- 그림체 C: 물감 얼룩(옅은 저주파 명암)을 더하고 번짐을 조금 키움(.34→.42). 처음엔 얼룩이 너무 짙어 지저분 → 명암 범위 0.90~1.02로 낮춤.
- 배경음 1 뒷부분: 1판은 '검산 끝' 뒤에도 4마디 반복이 그대로 돌아 IV(F) 화음에 걸린 채 끊겼고, 도장 화음이 G 마디 위에 겹쳤다 →
  ① 검산 끝 마디부터 I → IV·V → I 로 끝맺고 마지막 마디는 으뜸화음 한 번 + 반짝 세 음, 1초 페이드
  ② 긴 설명 구간(s5~s8)은 한 겹 덜어 숨 쉬게(뒷박 화음 절반, 16분 셰이커 빼고 마디 첫 박에 첼레스타 한 음)
  ③ 바순(모리 대답)이 F1 같은 너무 낮은 음으로 떨어지던 것 한 옥타브 올림 ④ 핵심 첫마디(quiet) 동안 새 음은 0.35배.
- 모리 3판: `voices/mori-v3`(재치20대_중간 테이크에서 어색한 리액션을 빼고 쉼을 줄인 10.5초 기준 소리)로 EX.09 모리 6줄을 다시 읽힘(`jobs/ex09-mori3.json`).
  테이크는 받아쓰기 통과 + 중앙 음높이 150~180Hz(젊게, 줄마다 들쭉날쭉하지 않게)로 손으로 골랐다 — 110~130Hz 테이크는 나이 들게 들려 뺐다.
  리액션: "흐음, 인정."은 어느 테이크도 '흠 인정'으로 뭉개져 "흠. 인정할게."(168Hz)로 바꿈, "거짓말." 뒤에 0.14초 숨을 넣어 받아치는 박자를 줌. "에이, 거짓말"은 '에이'가 영어 A처럼 들려 안 씀.
- 받아쓰기: 전 줄 통과, L09 "수험생들" 첫 글자만 음악 아래에서 '수원생'으로 적힘(음악 끄면 통과).
