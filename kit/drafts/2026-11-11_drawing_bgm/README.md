# 그림체·배경음 고도화 시안 (2026-11-11) — 아직 채택 전

사용자 요청: "도리 쇼츠를 드로잉 스타일을 가미해서 고도화, 잘나가는 쇼츠 BGM을 참고해서 설명하는 박자에 맞게 은은하게".
시험 편: EX.09 수능 스마트안경(이미 올린 편 — 다시 올리지 않는다, 시안용으로만 다시 렌더).

## 그림체 — `sketch.js`
index.html 끝에 `<script>window.SKETCH={style:'A'}</script><script src="sketch.js"></script>`.
- 0 지금 그대로 · A 연필 스케치(흔들리는 선 + 초당 8번 선 끓임 + 겹선 + 캐릭터 오른쪽 아래 연필 음영) · B 색연필(A + 거친 색칠 결) · C 그림책 수채(번지는 물감 + 종이 결).
- 공통: 화면 전체 종이 결(곱하기), 벽 여백 연필 낙서(별·소용돌이·구름), 마루 연필 결. 글자(말풍선·자막·숫자)는 흔들림을 아주 작게.
- 결정적 렌더: 선 끓임은 render(t) 시각으로 정해진다. 렌더 시간은 프레임당 약 0.4초(필터) — 55초 영상 약 6분.

## 배경음 — `music.py` (mix.py 가 BED=P|L|M 일 때)
- 실제 악기 샘플(`fetch_sf.sh`)로 100 BPM: P 통통 피치카토 · L 로파이 피아노 · M 마림바 미니멀.
- 말 박자 맞춤: `BPM=100 python3 build_voice.py` — 줄 시작을 8분음표(0.3초) 격자에(쉼은 최대 0.22초 늘어남, 55초 편에 +0.8초).
- 멜로디는 말 틈에서만 대답(도리 뒤 높은 반짝 · 모리 뒤 낮은 능청), 모리 줄은 음악을 끄지 않고 낮은 옷으로 갈아입음, 장면 전환 올라가는 꾸밈, 숫자 단어 작은 화음, 검산 끝 으뜸화음, 쏙에 끝음.
- 크기: `BED_UNDER=13.5` — 말하는 동안 목소리보다 13.5dB 아래(은은하게). 받아쓰기: M 전부 통과, P L09 · L M00 한 줄씩 확인.
