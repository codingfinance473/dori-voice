## 작업 기록
- 처음엔 저장소 쓰기(push)가 자동으로 거절돼 대사·화면·썸네일을 무음 임시 시간표(별도 폴더)로 먼저 짰다 → 사용자 "push 허용" 뒤 목소리 작업.
- KOSIS·ECOS 키는 저장소 밖 작업 공간(~/.config/market-data/keys.env)에만 두고 출력하지 않음.
- 목소리: ex07-01(13줄) → ex07-02(다시 만든 줄). L10 "위안화와 달러는 작년보다"는 네 테이크 모두 '위아와'·'장면보다'로 들려 "같은 기간, 중국 위안이랑 미국 달러는, 일 년 전보다 비싸졌고"(L10c, 1.0)로 바꿔 L10 자리에 씀. L11 "엔화는"은 늘 '에나는'(엔화의 실제 발음 [에놔])으로 적혀 spell.json alt 에 '에나·에너'를 더하고 첫 작업 테이크(00_1, "5퍼센트 싸졌대" 또렷)를 씀 — "일본 엔화는"·"일본 돈 엔화는"은 '싸졌대'가 '써줬대'로 뭉개져 안 씀. L04 는 받아쓰기 창이 끝을 잘라 '확인'이었지만 앞뒤 쉼을 붙이면 "6.3퍼센트 줄었어" 통과(keep).
- 사용자 의견(21:59) "내수가 안 좋아지거나 환율 이슈 아닐까" → KOSIS 로 점검: 국내 온라인쇼핑 3분기 +6.4%·소매판매(불변) -0.5%, 화장품 국내 온라인 +9.8% vs 직구 -13.3% → "소비 전체 감소"보다 "환율 + 국내로 옮겨 감"에 가까움(옷은 국내도 -4.6%). 고정 댓글 둘째 줄로 넣고 영상 장면 추가 여부는 사용자에게 물음(예비 목소리 N01·N01b 는 만들어 둠, 지금 영상에는 안 씀).
- 시간표 61.7초. render.py qa 통과, qa_sheet·eyes_sheet 직접 확인. 2장 막대는 장면이 열리자마자 올라오게(s2+.15).
