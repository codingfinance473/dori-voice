# EX.10 담뱃값 8500원 — 숫자·근거 대조표 (확인한 날 2026-11-12)

- 형식: 도리·모리 2인 형식(공통 지침 15절). 옷 `tax`(값의 74%가 세금·부담금 — 직전 편 EX.09 `detective`, EX.08 `winter` 와 다르게).
- 질문: "담뱃값 인상, 진짜 8500원 되는 걸까?" → 8500원은 2026-11-10 전문가 포럼의 제안이고, 보건복지부는 "현재 인상을 검토하고 있지 않다".
- 기관 원문(의학한림원 포럼 자료·복지부 설명자료)은 작업 공간에서 열리지 않아, 같은 내용을 옮긴 보도 두 곳 이상으로 맞췄다. 세금·부담금 금액은 법 조문 금액(한국보건사회연구원 정리표)과 보도로 맞췄다.
- 찬반(올려야 한다/말아야 한다)·금연 권유·흡연율 전망은 대사에 넣지 않았다(조언·정책 주장 없이 "정해졌나"만 검산).

## 쓰지 않은 것
- 제안자의 추산(궐련 판매량 −35.6%, 성인 흡연율 17.0% → 14.0%, 세수 +2조 7600억 원) — 한 사람의 시나리오 추산이고 찬반 논거라 영상에 넣지 않았다.
- 8500원 산출 근거(구매력평가 기준 10달러 × 약 816원 ≈ 8163원 → 8500원) — 농민신문 한 곳에서만 확인해 대사·고정 댓글에 넣지 않았다.
- "법을 바꿔야만 오른다"는 단정 — 담배소비세·개별소비세에는 시행령으로 30% 범위에서 조정하는 탄력세율이 있고 제조사가 값을 신고해 올릴 수도 있어, 대사는 지난 인상의 사실("국회에서 법을 바꾸고서야 올랐대")로만 말했다.
- 6월 장관 간담회 발언("가격정책을 어떻게 가져갈지 검토")은 고정 댓글 후보였으나 보도 한 곳(아시아타임즈 06-16)만 확인해 뺐다.
- 전자담배·액상 규제 — 주제 밖.

## 대사 메모
- "제안"은 도리·모리 두 목소리 모두 받아쓰기에 '제한·재환'으로 잡혔다(테이크 16개 중 15개) — 뜻이 달라져 말은 "올리자고 한 말"·"정해진 건 아니네"로 바꾸고, "제안"은 화면(딱지·정리 카드)에 쓴다.
- "포럼"은 '프럼·포함해서'로 → 말에서는 빼고 화면에 "미디어 포럼".
- "팔천오백 원"·"사천오백 원 중에 삼천삼백 원쯤"·"십이만 원"·"이천오백 원"은 그대로 잘 읽힘(받아쓰기 8500·4500·3300·12만·2500).
- 실제 속도는 어림(53초)보다 빨라 44.5초 — 숫자 읽기 줄이 글자 수보다 짧게 나온다.
