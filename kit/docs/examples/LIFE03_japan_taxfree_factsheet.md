- "영수증에 물건 하나라도 없으면 영수증 전체 환급 불가"(일부 보도) — 관광청 FAQ는 상품별로 결과가 나올 수 있고 영수증 전체가 일률적으로 불가는 아니라고 함 → 영상에서 다루지 않음.
