# LIFE.09 파킹통장 매일 이자 — 숫자·제도 대조표 (확인한 날 2026-11-14)

- **2판(2026-11-14, 최종): 도리 단독 설명형.** 사용자 의견 "난 모리~랑 인정 이런 포맷 좀 유치한 것 같아. 이 내용은 단순 설명이니까 도리가 혼자 하되 좀 더 내용을 알차게" → 모리 줄(M01·M00·M02·M03·M04)을 빼고, 도리가 스스로 묻는 줄(D04 "매일 받으면, 이자에 이자가 붙어서 더 많아질까?"·D06 "그럼 연 팔 퍼센트 통장이면, 네 배일까?")로 잇고, 계산법 줄(D02)과 새 장면 s5 "이자를 키우는 건?"(D09·D10 — 매일 받기 +117원 vs 금리 +1%p +8만 6404원)을 더함. 1판(2인 형식)은 쓰지 않는다.

- 형식: 도리·모리 2인 형식(공통 지침 15절). 옷 `tax`(이자·세금 — 초록 바이저·안경·조끼). 끝 문구 ③(`cta_life_3`, 9를 3으로 나눈 나머지 0).
- 주제: 사용자가 준 제목 "파킹통장 이자, 매일 받으면 진짜 얼마일까? #파킹통장 #파킹통장금리".
- 방향: LIFE.08(2026-11-12 사용자 결정)과 같이 **상품·은행 이름은 화면·대사·설명란에 쓰지 않는다** — 이름은 이 대조표에만. 가입 권유·순위 없음.
- 한 줄: 매일 받으면 복리로 '쑥쑥' 불어난다고 하지만, 천만 원·연 2%에서 한 달에 한 번 받을 때보다 1년에 117원 더 붙는다. 이자를 정하는 건 받는 횟수보다 금리 × 넣은 돈(구간)이다.
- 왜 지금: 한국은행이 7·8월 기준금리를 연달아 올려(연 3.00%, 10/22 동결, 다음 결정 11/26) 파킹통장 금리 인상·'연 8% 파킹통장' 보도가 이어짐(비즈워치 9/24, 경향신문 9/26, 딜사이트 9/27, SBS Biz).

## 쓰지 않은 것
- 상품·은행 이름, "어디가 낫다"·가입 권유, 순위.
- 매일 받을 때 세금의 10원 미만 끝수 처리 — 은행·세목별 처리가 공식 자료로 하나로 확인되지 않아 영상·댓글에서 뺌. 고정 댓글에는 "은행이 원 단위로 끊어 계산해 몇 원씩 다를 수 있다"만.
- 기준금리 숫자(연 3.00%)는 영상에 넣지 않음(왜 지금 메모에만). 넣으려면 ECOS 로 다시 확인.
- 예금자보호 1억 원은 영상에서 빼고 2판 고정 댓글에만(8% 상품이 저축은행이라 덧붙임).

## 올리기 직전 다시 볼 것
- 8% 상품 조건(30만 원 · 0.6% · 0.3%)이 그대로인지 — 9월 보도 기준. 바뀌었으면 4장면·정리 카드·고정 댓글의 142원·55원이 달라진다.
- 11/26 금통위 뒤 파킹통장 금리가 크게 바뀌어도 영상의 2%는 '계산용 가정'이라 그대로 맞음.
