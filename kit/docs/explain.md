# 숫자 검산(설명형) — 「도리의 정보주머니」 퀴즈 없는 설명 편

- 만든 날: 2026-11-01. 공통 지침(`common_guide.md`)이 앞선다.
- 왜(사용자 판단 2026-11-01): 퀴즈만 이어 가면 채널이 "퀴즈 채널"로 굳어 보인다. 퀴즈는 접근성을 높이려던 수단 — 데이터로 질문 하나("꺾였나?")에 답하는 설명 편을 섞는다.
- 위쪽 칩: "숫자 검산"(파란 점 #5B8CFF). 보기·카운트다운·"너도 찍어 봐"·정답 연출 없음.

## 흐름 (45~60초)

질문 한 줄(지금 화제인 숫자) → 근거 장면 3~4개(월별 막대 · 증가율 · 하루 평균 · 원인 지표 등, 장면마다 한 가지) → 반대 신호도 한 장면 → 정리 카드(✔ 근거 + △ 반대 신호) + "이걸로 검산 끝!" → 열린 질문 한 줄(다음 달 예상 등) → 구독·좋아요 한 줄(`cta_life_N`, 공통 지침 9절) → "볼주머니에 쏙!"

## 규칙

- 결론은 숫자로 말할 수 있는 만큼만: "아직 꺾였다고 말하긴 어려워"처럼. 전망·투자 조언 금지(설명란에 "투자 조언이 아니라 공개된 숫자를 정리" 한 줄).
- 반대 신호를 꼭 하나 넣는다(예: 하루 평균 감소). 한쪽 숫자만 고르지 않는다.
- 계산한 숫자(조업일수, 하루 평균, 배수)는 화면 단위 줄에 "(계산)"과 식을 적는다.
- 고정 댓글은 공통 지침의 정보 덧붙임(2026-11-05 — 예상 묻기·이모지 투표는 그만): 집계 기준 차이, 계산 식, 화면에 못 넣은 확인된 숫자, 내 경우 확인 경로. 설명형은 정답이 없는 형식이라 결론 숫자를 적어도 된다. 예: `examples/EX04_업로드문구.md`.

## 템플릿

- `kit/templates/explain/` — EX.01 반도체 화면(`index.html`·`thumb.html`), 시간표(`build_voice.py`: 장면 s1~s6 + s9, WORD 이름 wdrop·wpeak·wdip·wrec·wsame·wday·w8·wmore·wmem·wearly·wnov), 소리(`mix.py`), 퀴즈 템플릿에서 바꾼 방법(`_make_ex01.py`).
- 새 편: `new_episode.sh` 로 폴더를 만든 뒤 위 네 파일을 덮어쓰고, 장면 마크업·장면 JS·도리 연기 표(EX·GZ·HOPS·ARMR·ARML·marks)를 바꾼다. 색종이(#conf)는 숨겨 둔다.

## 받아쓰기 교훈(EX.01)

- "메모리"는 "매몰이·내머리"로 자주 뭉갠다 → "반도체 값"으로.
- "일러"는 "읽어"로 → "말하긴 어려워".
- 숫자 줄 바로 뒤 효과음은 다음 줄 첫마디를 덮는다(L08 끝 → L09 "시월은" 실패) — 줄 사이가 짧으면 효과음을 뺀다.

## EX.04 국민연금 수령액(2026-11-05) — 검색 데이터로 주제 고르기

- 사용자 요청 "검색 잘되는 류로, 공수 많이 들어도": blog-radar(`codingfinance473/blog-radar`)를 세션에 붙여 그날 수집분(`radar.py rank --per 30`)을 훑고, 쇼츠 후보 20개를 `radar.py dispatch --keywords … --wait 14` → `pull` → `rank --adhoc` 으로 따로 재서 네이버 데이터랩 지수·최근 7일 배수·12주 흐름으로 비교했다(약 15분). '국민연금 수령액'이 11/1 공표통계 보도 직후 주간 11→126(10.6배), '국민연금 수령나이' 66 꾸준 → 선정. 금 시세·엔화 환율은 지수가 수천이지만 매일 바뀌는 시세라 뺐다.
- 화면 장면 s1 질문 → s2 수급자 수 → s3 금액별 분포(괄호 + "가장 많아!") → s4 가입기간별 평균 → s5 반대 신호(적정 생활비) → s6 수령나이 계단 → s8 정리 카드(!·✔·△) → s9. 도리 옷 `tax`. 54초.
- 받아쓰기: "받기 시작하는 **나이**는" → 네 테이크 모두 '라인은' → 말을 "육십구 년생부터는, 예순다섯 살부터 받는대."로 바꿨다. "예순다섯"은 '예순 5', "두 배"는 '2배'로 적힘 → spell.json alt.
- 숫자 줄 끝 효과음(L02 끝 마림바)이 0.35초 뒤 L03 "십일 년"을 덮어 완성 믹스 1/3 → 뺐다. 반대 신호 줄(L08) 끝 슬픈 음도 0.7초 뒤 L09 첫마디와 겹쳐 두 음 0.5초로 줄였다.
- 한 곳에서만 확인된 숫자(월 200만 원 이상 13만 3946명·최고 329만 원)는 넣지 않았다.

## EX.07 해외직구 감소(2026-11-08) — '이유'는 공식 숫자를 나란히

- 블프(11/27) 앞 주제. 국가데이터처 「2026년 9월 온라인쇼핑동향」(11/2) 3분기 해외직구 1조 9893억 원 -6.3%를 KOSIS 원표(101/DT_1KE1009, 2014Q1~2026Q3)로 받아 '2014년 이후 처음 두 분기 연속 감소'를 직접 검산했다(줄어든 분기 2015Q4·2022Q4·2026Q2·2026Q3뿐).
- 감소 이유는 데이터처 공식 설명이 없고 보도는 "고환율로 풀이"뿐 → 원인을 말로 단정하지 않고 같은 기간 한국은행 ECOS 매매기준율 3분기 평균(위안 +9.1%·달러 +2.8%·엔 -5.0%)을 나라별 직구(중국 -9.1%·미국 -11.1%·일본 +32.4%)와 나란히 보여 줬다("환율 오른 곳은 덜, 내린 일본은 더 샀대"). 반대 신호 = 일본 +32.4%.
- 사용자 가설 "내수 탓?"은 KOSIS 로 점검해 고정 댓글에(국내 온라인쇼핑 +6.4%, 화장품 국내 +9.8% vs 직구 -13.3%).
- '나라만 늘었다' 같은 말은 전체 지역을 다 보고 쓴다 — 캐나다(+3.8%) 등 작은 곳도 늘어 "일본만"을 "중국·미국은 줄고 일본은 늘었어"로 고쳤다.
- 받아쓰기: "위안화와"는 '위아와', "작년보다"는 '장면보다'로 적힘 → "중국 위안이랑 미국 달러는, 일 년 전보다". "엔화는"은 늘 '에나는'([에놔] 발음) → spell.json alt `"엔화": ["엔화","에나","에너"]`; "일본 엔화는"은 오히려 '싸졌대'가 '써줬대'로 뭉개졌다.
- 화면: 매년 3분기 '택배 상자 기둥' 막대, 환율은 글자 동전(¥는 위안·엔 둘 다라 안 씀) 세 장 + 아래 '직구 ▲▼' 줄. 옷 `news`. 61.7초.

## EX.08 도시가스 요금(2026-11-09) — 도리·모리 2인 형식 첫 편

- 공통 지침 15절의 뼈대로 만든 첫 편(54.8초): 도리 "올겨울 집 가스 요금, 거의 그대로래!" → 모리 "거짓말. 올봄에 기름값 올랐다던데?" → 가스공사 도매요금표(주택용 20.8495원/MJ, 2024년 8월부터 동결) + 서울 소비자요금(8월 +0.7%) → 모리 "그럼 올랐다는 말은 뭔데?" → 산업용 도매요금 2월 16.97 → 11월 26.50원(+56%) → 모리 "집은 왜 안 올렸는데?" → 정부 동결·가스공사 민수용 미수금 13조 8649억 원(2025년 말) → 모리 "그래서, 그게 내 지갑이랑 무슨 상관인데?" → 서울 2,000MJ 집 계산 약 5만 1천 원, 오른 몫 월 350원쯤 → "흐음, 인정." → 검산 끝. 반대 신호(서울 소매 +0.7%, 지역별 소매요금 차이)는 모리 반론과 정리 카드 △로.
- 주제는 blog-radar 그날 자료의 쇼츠 후보 1위(도시가스 요금조회 — 네이버·구글·유튜브 자동완성 모두 1위, 시즌 1.4배). 사건 이름(중동 전쟁·호르무즈)은 쓰지 않고 "올봄에 기름값 올랐다던데"까지만.
- 숫자 출처는 요금표 원문 둘(가스공사·서울도시가스 2026-11-01)로 직접 확인. 보도 한 곳뿐인 숫자(서울 소매 인상폭 0.1573원/MJ)는 대사에서 "조금, 1%도 안 돼"로만 말하고 숫자는 고정 댓글에.
- 대사 길이: 1판 309자(공백 제외) → 임시 시간표로 75초가 나와 줄였다. 글자 수 × 0.21초(도리)·0.24초(모리) + 쉼으로 먼저 어림한다.
- 받아쓰기: "가스요금" → '가수금/갈수요금'(붙여 쓴 복합어) → "가스 요금"으로 띄워 통과. 긴 줄 L02b(도매+서울, 8.8초)는 네 테이크 모두 흔들려 둘로 나눔(L02c·L03c). "십삼 조 넘게"는 '13,000원'으로 적혀 "십삼 조 원 넘게"로. "켰어"는 '꼈어/했어' — "너희 집(너이집)"은 '너의지'로 적히는 게 정상 발음. 배경음이 줄 첫마디를 덮은 줄(L02c·L03c·L04b·L08)은 quiet·WEAK .5로 비워 통과(NOBED=1 비교로 확인).
- 화면: 겨울 거실(나무 마루), 콜드오픈은 "?원" 고지서 + 눈 오는 창문, 근거는 평선 그래프(27개월째 그대로 칩), 반전은 집·공장 그림 + 같은 축 막대 넷, 미수금은 고지서 더미 + 큰 숫자(처음엔 흐리게 두고 단어에 맞춰 선명하게 — 빈 순간 없이), 계산은 영수증 줄 셋 + 합계. 도리 옷 `winter` 첫 사용. 모리 A 크림.
- 2026-11-10 사용자 의견으로 3판(56.5초): 배경음이 줄 동안 통째로 꺼짐 → 끊지 않게, 제목과 고지서 카드 겹침 → 카드 내림, 모리가 누군지 모름 → 자기소개 한 줄 + 명패, 표정이 목소리와 안 맞고 눈을 착하게 뜸 → 늘 반쯤 감은 눈, 티키타카 → 반응 쉼 0.18초 + 모리 목소리를 4번에서 3번으로(나란히 비교해 고름). 자세한 규칙은 공통 지침 15절.

## EX.09 수능 스마트안경(2026-11-10) — 규칙 편도 2인 형식으로

- 수능(11/19) 9일 전, 교육부가 11/9 수험생 유의사항을 다시 낸 다음 날 만든 편(51.8초). 숫자가 적은 '규칙' 주제라 근거 장면을 규칙 하나씩(착용 = 사용 간주 → 그해 무효 + 다음 해 정지 / 감독관 확인 거부도 같은 처분 / 3년은 추진 중, 올해 1년)으로 짜고, 계산은 지원자 55만 1864명 ÷ 시험장 1312곳 ≈ 420명(화면만, 대사엔 안 씀). 반대 신호는 모리의 "뉴스엔 삼 년 못 본다던데?" → "아직 추진 중, 올해는 일 년" 정정으로.
- 빼는 것: 적발된 대학 이름·사건, 기기 구분이 어려운 이유(피하는 요령처럼 읽힘), 한 단체 설문, 한 곳에서만 확인한 말(시험 뒤 돌려받음).
- 받아쓰기: **"무효"는 목소리 C로 테이크 12개 모두 '무료·무휴·무열'**로 잡혔다 — "무료"로 들리면 뜻이 반대라 말은 "시험이 날아간대"로, "무효"는 화면·자막·정리 카드로만. "그해"는 '그게·그에' → "올해". spell.json alt `"날아": ["날아","날라","나라"]`, `"지원자": ["지원자","지연자"]`.
- **테이크 끝 꼬리도 본다(11-11)**: L03 테이크 끝에 말이 끝난 뒤 0.13초 쉬고 0.06초짜리 잡음(다음 말 첫소리 같은 조각)이 붙어 뚝 잘렸다 — 받아쓰기는 통과해도 "수능도 못 봐"에서 영상이 끊기는 느낌(사용자). 마지막 소리 덩어리가 0.12초 이하이고 앞에 0.05초 넘는 쉼이 있으면 잘라 내고 0.04초 페이드. 줄 끝 효과음은 말하는 쪽 바뀜 신호와 겹치면 뺀다.
- 테이크 길이도 본다: L07 첫 테이크는 안에 2.2초 쉼이 있어 10.7초 — 시간표가 61초로 늘었다가 다른 테이크로 51.8초.
- 모리 줄은 EX.08 에서 통과한 "난 모리. 근거 없는 말은 안 믿어."(ex08-05 t01)·"흐음, 인정."(ex08-04 t05)을 c_index 후보로 그대로 썼다 — 같은 말은 다시 만들지 않는다.
- 화면: 시험 책상 정물(수험표·답안지·시계 + 경첩에 카메라 점이 있는 상표 없는 안경), 결과 상자·2단계 상자·제출 바구니는 장면이 열릴 때 흐리게 먼저 두고 단어에 맞춰 또렷하게(빈 카드 없이). 3년은 같은 축 점선 막대, 1년은 실선. 도리 옷 `detective`.
