# 숫자 검산(설명형) — 「도리의 정보주머니」 퀴즈 없는 설명 편

- 만든 날: 2026-11-01. 공통 지침(`common_guide.md`)이 앞선다.
- 왜(사용자 판단 2026-11-01): 퀴즈만 이어 가면 채널이 "퀴즈 채널"로 굳어 보인다. 퀴즈는 접근성을 높이려던 수단 — 데이터로 질문 하나("꺾였나?")에 답하는 설명 편을 섞는다.
- 위쪽 칩: "숫자 검산"(파란 점 #5B8CFF). 보기·카운트다운·"너도 찍어 봐"·정답 연출 없음.

## 흐름 (45~60초)

질문 한 줄(지금 화제인 숫자) → 근거 장면 3~4개(월별 막대 · 증가율 · 하루 평균 · 원인 지표 등, 장면마다 한 가지) → 반대 신호도 한 장면 → 정리 카드(✔ 근거 + △ 반대 신호) + "이걸로 검산 끝!" → 열린 질문 한 줄(다음 달 예상 등) → 구독·좋아요 한 줄(`cta_life_N`, 공통 지침 9절) → "볼주머니에 쏙!"

## 규칙

- 결론은 숫자로 말할 수 있는 만큼만: "아직 꺾였다고 말하긴 어려워"처럼. 전망·투자 조언 금지(설명란에 "투자 조언이 아니라 공개된 숫자를 정리" 한 줄).
- 반대 신호를 꼭 하나 넣는다(예: 하루 평균 감소). 한쪽 숫자만 고르지 않는다.
- 계산한 숫자(조업일수, 하루 평균, 배수)는 화면 단위 줄에 "(계산)"과 식을 적는다.
- 고정 댓글은 퀴즈 대신 예상 묻기: "📈 다시 늘어난다 / 📉 더 줄어든다 — 이모지만 남겨도 OK".

## 템플릿

- `kit/templates/explain/` — EX.01 반도체 화면(`index.html`·`thumb.html`), 시간표(`build_voice.py`: 장면 s1~s6 + s9, WORD 이름 wdrop·wpeak·wdip·wrec·wsame·wday·w8·wmore·wmem·wearly·wnov), 소리(`mix.py`), 퀴즈 템플릿에서 바꾼 방법(`_make_ex01.py`).
- 새 편: `new_episode.sh` 로 폴더를 만든 뒤 위 네 파일을 덮어쓰고, 장면 마크업·장면 JS·도리 연기 표(EX·GZ·HOPS·ARMR·ARML·marks)를 바꾼다. 색종이(#conf)는 숨겨 둔다.

## 받아쓰기 교훈(EX.01)

- "메모리"는 "매몰이·내머리"로 자주 뭉갠다 → "반도체 값"으로.
- "일러"는 "읽어"로 → "말하긴 어려워".
- 숫자 줄 바로 뒤 효과음은 다음 줄 첫마디를 덮는다(L08 끝 → L09 "시월은" 실패) — 줄 사이가 짧으면 효과음을 뺀다.

## EX.04 국민연금 수령액(2026-11-05) — 검색 데이터로 주제 고르기

- 사용자 요청 "검색 잘되는 류로, 공수 많이 들어도": blog-radar(`codingfinance473/blog-radar`)를 세션에 붙여 그날 수집분(`radar.py rank --per 30`)을 훑고, 쇼츠 후보 20개를 `radar.py dispatch --keywords … --wait 14` → `pull` → `rank --adhoc` 으로 따로 재서 네이버 데이터랩 지수·최근 7일 배수·12주 흐름으로 비교했다(약 15분). '국민연금 수령액'이 11/1 공표통계 보도 직후 주간 11→126(10.6배), '국민연금 수령나이' 66 꾸준 → 선정. 금 시세·엔화 환율은 지수가 수천이지만 매일 바뀌는 시세라 뺐다.
- 화면 장면 s1 질문 → s2 수급자 수 → s3 금액별 분포(괄호 + "가장 많아!") → s4 가입기간별 평균 → s5 반대 신호(적정 생활비) → s6 수령나이 계단 → s8 정리 카드(!·✔·△) → s9. 도리 옷 `tax`. 54초.
- 받아쓰기: "받기 시작하는 **나이**는" → 네 테이크 모두 '라인은' → 말을 "육십구 년생부터는, 예순다섯 살부터 받는대."로 바꿨다. "예순다섯"은 '예순 5', "두 배"는 '2배'로 적힘 → spell.json alt.
- 숫자 줄 끝 효과음(L02 끝 마림바)이 0.35초 뒤 L03 "십일 년"을 덮어 완성 믹스 1/3 → 뺐다. 반대 신호 줄(L08) 끝 슬픈 음도 0.7초 뒤 L09 첫마디와 겹쳐 두 음 0.5초로 줄였다.
- 한 곳에서만 확인된 숫자(월 200만 원 이상 13만 3946명·최고 329만 원)는 넣지 않았다.
