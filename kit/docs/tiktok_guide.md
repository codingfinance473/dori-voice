# 틱톡판 — 「도리의 정보주머니」 틱톡 업로드 지침

- 만든 날: 2026-11-01 (사용자 지시: 틱톡용 영상을 만들 때마다 틱톡 SEO에 맞춘 설명·해시태그·멘션을 자동으로 써서 함께 준다).
- 공통 지침(`common_guide.md`)을 따르되, 틱톡에 올리는 편은 이 문서를 더한다.

## 1. 영상 규격 (리워드 조건)

| 항목 | 기준 |
|---|---|
| 길이 | **1분 넘게, 목표 65~75초** — 크리에이터 리워드는 1분 이상 오리지널 영상만 받는다 |
| 화면 | 1080×1920, 워터마크·유튜브 로고·"구독" 문구 없음 |
| 첫 3초 | 핵심 검색어를 **화면 글자와 대사로 둘 다** 보여 준다(틱톡은 말소리를 받아써서 주제를 분류한다) |
| 늘릴 때 | 억지로 늘리지 않고 "한 겹 더" 장면(확인된 숫자 하나 더)을 넣는다 — 예: 화장품 편 중국 비중 2021년 53.2% → 올해 14.2%, 소고기 편 무게 18.7만 톤 vs 13.8만 톤 |
| 유튜브 원본 | 이미 1분을 넘고 지금 규칙(댓글 강요 없음·예고 없음)을 지키면 그대로 올린다 |

## 2. 매 편 함께 내는 업로드 문구 (자동 작성)

틱톡판을 만들면 영상·커버와 함께 아래 다섯 가지를 **틱톡_업로드문구**로 써서 낸다.

1. **설명(캡션)** — 3줄 안팎
   - 1줄: 사람들이 실제로 검색하는 문장을 그대로, 핵심 검색어를 맨 앞에(틱톡은 캡션 앞부분을 가장 무겁게 본다). 질문형.
   - 2줄: 검색어 변형 2~3개(연도·기간·비교어 "vs"·"순위"·"얼마부터")를 자연스럽게, 무엇을 볼 수 있는지. **정답·판정은 쓰지 않는다**(정답을 짐작하게 하는 말도 빼기).
   - 3줄(선택): 저장 유도 한 줄("○○ 전에 저장해 둬"). 댓글을 강요하지 않는다.
2. **해시태그 5개 이하** — ① 넓은 검색어 1 ② 좁은 검색어 2 ③ 시리즈(#숫자퀴즈·#생활검산) 1 ④ 채널(#도리의정보주머니) 1. #fyp·#viral·#추천 같은 일반 태그와 무관한 인기 태그는 넣지 않는다. 같은 묶음을 매 편 반복하지 말고 주제별로 바꾼다. 정답 나라만 콕 집는 태그는 피한다(보기 모두를 같은 무게로 넣거나 빼기).
3. **멘션(@)** — 주제와 직접 관련된 **공식 인증 계정만**(업로드 화면에서 @를 쳐서 파란 체크로 확인). 확인이 안 되면 넣지 않는다. 작은 계정에는 관련 멘션이 도달에 도움이 되지만, 무관한 계정 태그는 스팸으로 보인다. 매 편 "찾아볼 계정 후보"를 적어 주고, 확인은 사용자가 업로드 화면에서 한다.
4. **고정 댓글** — 공통 지침 그대로("🐹 정답 보기 전에 찍어 줘! / [질문] / A … / B … / C … / 번호만 남겨도 OK 👇"), 질문에 핵심 검색어를 한 번 넣는다.
5. **올리기 전 체크** — AI 생성 콘텐츠 설정 켜기(더 보기 → AI 생성 콘텐츠), 커버는 커버 이미지, 파일 이름은 검색어로(예: `화장품수출_1위_나라_숫자퀴즈.mp4`), 자동 자막 켜고 오탈자 확인.
