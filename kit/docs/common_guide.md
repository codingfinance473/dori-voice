# 도리의 정보주머니 — 공통 제작 지침

- 확정: 2026-10-29 (사용자 지시). 모든 시리즈(생활 정보 · 숫자 퀴즈 · 가격 검산(쇼핑))에 똑같이 적용한다.
- 시리즈 지침(「숫자퀴즈쇼츠_제작_프롬프트」, 「쇼핑검산쇼츠_지침」)과 다르면 **이 문서를 따른다**. 앞으로 만드는 모든 편에서 반드시 지킨다.

## 1. 매 편 산출물 — 딱 네 가지

| 산출물 | 규격 |
|---|---|
| 영상 1개 | MP4 1080×1920, 30fps, 업로드용 원본 하나. 공유용 10MB 버전·A/B 영상은 만들지 않는다. |
| 제목 1개 | 그대로 붙여 넣을 확정안 하나. 40자 안팎, 답(정답·판정)을 제목에 쓰지 않는다. |
| 설명 1개 | 그대로 붙여 넣을 설명란 전문(아래 3절 틀). |
| 썸네일 1개 | 1080×1920 JPG(2MB 미만), 어느 화면에서도 핵심이 잘리지 않는 배치(아래 2절). 가로형·A/B 후보는 만들지 않는다. |

- 숫자 대조표(숫자·기관·기준 기간·확인한 날·링크)와 받아쓰기 점검은 작업 기록으로 남긴다. 사용자에게 보내는 것은 위 네 가지다.

## 2. 썸네일 — 안 잘리게

유튜브는 쇼츠 썸네일을 화면마다 다르게 자른다. 홈·구독 피드 일부는 가운데 4:5(1080×1350), 일부 표시는 가로에 가까운 3:2 띠로 보인다는 보고가 있고, 쇼츠 선반·검색·채널 탭에서는 위아래 UI가 그림을 덮는다(대략 위 380px · 아래 380px · 오른쪽 120px).

| 영역 (1080×1920 기준) | 넣는 것 |
|---|---|
| **핵심 띠** y 600~1320, x 90~960 | 제목(2줄 이내, 줄당 8자 안팎, 140px 이상) + 핵심 그림 하나(국기 줄·숫자 하나·상품 하나) |
| **보조 영역** y 380~1540, x 60~960 | 시리즈 칩, 도리(얼굴이 보이게), 소품 |
| 그 밖 (위 380 · 아래 380 · 오른쪽 120px) | 배경만 — 글자·얼굴·숫자를 두지 않는다 |

- 답을 알려 주지 않는다: 정답 국기나 판정 도장을 표시하지 않고, "?"는 따로 떨어진 원으로 둔다(특정 보기 위에 얹지 않는다).
- 확인: 업로드 전 가운데 4:5 · 1:1 · 3:2로 자른 미리보기 세 장과 UI 가림 표시를 함께 보고, 세 장 모두에서 제목과 핵심 그림이 다 보여야 통과.

## 3. 설명란 틀

```
[첫 줄: 검색될 핵심어를 넣은 질문 — 예: "한국 화장품 수출 1위 나라는 어디일까? K뷰티 수출 국가 순위 숫자 퀴즈"]
[둘째 줄: 무엇을 볼 수 있는지 한 줄 — 답은 말하지 않는다. 핵심어 2~3개를 자연스럽게 한 번씩]

자료
· [발행 기관] [자료 이름]([발표일]) — [쓴 숫자와 기준 기간]
· [최신 수치를 옮긴 보도 매체 · 날짜]

[비유·어림을 썼다면 무엇의 비중인지 한 줄]
영상 속 목소리는 AI로 만들었어요.

#[핵심 주제어] #[넓은 주제어] #숫자퀴즈 #[보조 주제어] #[보조 주제어2] #도리의정보주머니 #Shorts
```

- 화면에는 기관명 + 기준 기간만, 뉴스 매체명·보도 날짜는 설명란에만 둔다(2026-10-28 확정).
- **고정 댓글로 정답 전에 찍게 한다**(2026-10-31): 업로드하자마자 채널 이름으로 "🐹 정답 보기 전에 찍어 줘! / [질문] / A … / B … / C … / 번호만 남겨도 OK 👇"를 달고 고정한다(정답은 적지 않는다). 영상에서는 카운트다운 바로 앞에 도리가 "고정 댓글에 번호로 먼저 찍고 봐!"(공용 소리 `pin_ask`)를 말하고 화면에 "📌 고정 댓글에 찍기!" 칩을 띄운다. 끝 질문은 "뭐 찍었어?" 대신 주제에 맞는 경험 질문(예: "너는 하루에 밥 몇 공기 먹어?"). 매 편 고정 댓글 문구를 제목·설명과 함께 보낸다. 초반엔 달리는 댓글에 짧게 답글을 단다.
- **다음 편을 예고하지 않는다**(2026-10-30 확정): 영상 끝인사는 "볼주머니에 쏙!"만, 끝 화면에 "다음 숫자 퀴즈" 카드 없음, 설명란에 다음 편 줄 없음.
- **검색 친화(SEO)**(2026-10-30): 사람들이 실제로 치는 말을 쓴다(예: "화장품 수출 순위", "K뷰티", "소고기 수입"). 제목·설명 첫 줄·해시태그 앞쪽에 같은 핵심어가 들어가게 한다.
- **해시태그 6~8개, 공백 없이, 모두 영상과 직접 관련된 것만**: 유튜브는 설명의 해시태그 중 최대 3개를 제목 옆에 보여 준다 — 맨 앞 셋은 ① 핵심 주제어(#화장품수출) ② 넓게 찾는 말(#K뷰티) ③ 시리즈(#숫자퀴즈). 그 뒤 보조 주제어 2~3개, 채널(#도리의정보주머니), #Shorts. 관련 없는 인기 태그·같은 말 반복은 넣지 않는다(60개를 넘기면 모두 무시되고, 무관한 태그는 삭제 사유).
- **설명란에 URL 주소를 넣지 않는다**(붙여 넣어도 설명에 들어가지 않는다, 2026-10-29 확정). 출처는 기관·자료 이름·발표일·보도 매체·날짜 글자로만 적고, 링크는 작업 기록(대조표)에만 남긴다.

## 4. 데이터 — 지금과 가장 가까운 최신 수치

1. **오늘 날짜부터 확인한다.** 그 숫자의 가장 최근 발표가 무엇인지 먼저 찾는다 — 월간(올해 누계) → 분기 → 연간 순.
2. **올해 누계가 있으면 그게 주 숫자다.** 예: 10월에 만들면서 재작년 연간을 쓰지 않는다 — 올해 1~7월이 있으면 "올해 7월까지"로 말하고, 연간 숫자는 추세·비교에만 쓴다.
3. **최신 발표가 나오는 곳**을 먼저 본다:
    - 관세청 수출입무역통계(TRASS)·보도자료 — 매월 1~10일·1~20일 잠정, 월간 확정
    - 산업통상자원부 월간 수출입 동향(매월 1일)
    - 통계청 KOSIS · 한국은행 ECOS
    - 농식품부·aT KATI 월간 수출 · 식약처 · 해수부 등 품목 담당 기관
4. **기관 원문이 열리지 않으면** 같은 수치를 옮긴 보도를 두 곳 이상 대조해 쓰고, 설명란에 그 보도를 적는다.
5. **두 번 확인한다.** 대본을 쓰기 직전과 업로드 직전에 새 발표(월초 수출입 동향 등)가 나왔는지 다시 본다. 더 새로운 숫자가 나왔으면 고친다.
6. **오래된 기간을 주 숫자로 써야 하면**(더 최신 국가별 자료가 아직 없을 때) 그 이유를 대조표에 남기고, 화면·대사에 기간을 그대로 말한다.
7. 숫자마다 기관 · 기준 기간 · 확인한 날을 대조표에 적는다.

## 5. 주제 찾기 — 뉴스만이 아니라

여러 곳에서 후보를 모으고, 후보마다 **"왜 지금"**과 **"최신 공식 숫자가 있는가"**를 같이 적어 고른다.

| 어디서 | 무엇을 본다 |
|---|---|
| 사람들의 검색 | 네이버 데이터랩(검색어 트렌드·쇼핑인사이트), 구글 트렌드(급상승·관심도), 네이버·구글·유튜브 자동완성("○○ 왜", "○○ 가격", "○○ 진짜"), blog-topic-radar가 매일 모으는 키워드 |
| 시사·생활 달력 | 제도 시행일(세금·지원금·요금·면세), 계절·명절·행사(수능, 김장철, 블랙프라이데이, 연말정산), 스포츠·연예·밈 화제 |
| 커뮤니티·SNS | "진짜 싸?", "왜 비싸?" 같은 질문과 소문 — 숫자로 검산할 수 있는 것만 |
| 통계 발표 일정 | 막 나온 숫자(월초 수출입 동향, 물가 동향, 분기 실적 통계) |
| 뉴스 | 착안 중 하나이자 확인 수단 |

- 고르는 기준: ① 지금 사람들이 궁금해한다(검색 오름세·화제·시기) ② 최신 공식 숫자가 있다 ③ 그림으로 보인다 ④ 지갑이나 생활에 닿는다 ⑤ 최근 편과 겹치지 않는다.
- 빼는 것(채널 약속): 정치·사건·재난·종목 추천·건강 조언.
