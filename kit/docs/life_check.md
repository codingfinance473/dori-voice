# 생활 검산 — 「도리의 정보주머니」 생활 정보 시리즈 지침

- 만든 날: 2026-10-31 (첫 편: 연말정산 카드 공제). 공통 지침(`common_guide.md`)이 이 문서보다 앞선다.
- 시리즈 이름: **생활 검산**(위쪽 칩 · 해시태그 #생활검산). 색은 주황 #E8833A(숫자 퀴즈 민트와 구분), 신용카드 같은 비교 대상은 남색 #6E7FA8.

## 흐름 (60~70초)

훅(질문 + 지금 열린·바뀐 것 하나) → 보기 3장(금액) + "너도 하나 찍어 봐!" + 카운트다운 → 도리가 흔한 오답을 찍음 → 힌트 하나 → 정답 → 규칙 한 줄(공식) → 비교 카드(무엇이 몇 배) → 반전(사람들이 잘못 아는 계산 순서·조건) → 결론 도장 "이걸로 검산 끝!" → 경험 질문 한 줄 → "볼주머니에 쏙!"

## 규칙

- 제도·요금·지원금처럼 **공식 기준이 있는 것만**. 근거 법령·기관 발표를 대조표에 적는다. 기관 원문이 막히면 같은 숫자를 옮긴 자료 두 곳 이상.
- **조언하지 않는다**: "체크카드 써"가 아니라 "체크카드는 30%래", "차이는 넘은 만큼에서 생긴대"까지만.
- 계산 예시는 무엇의 금액인지 밝힌다(예: "소득공제 금액 — 세금이 아님"). "연봉"을 쓰면 화면 칩에 "총급여 기준(비과세 빼고)".
- 표로 늘어놓기보다 **규칙 한 줄**(예: 기준선 = 총급여 × 25%, 1000만 원 오르면 250만 원씩)로 보여 준다 — 사용자 결정(2026-10-31).
- 시간 순서처럼 들리는 말 조심: 합계로 계산되는 규칙을 "기준선 전에는"처럼 말하면 쓴 순서 얘기로 오해된다 → "기준선만큼은".
- 국회 통과 전 개정안은 다루지 않거나 "아직 확정 아님"을 밝힌다.

## 화면 템플릿

- `kit/templates/life/`의 `index.html`·`thumb.html`·`money.js`(장면 s1~s9, EP.02 기준)를 시작점으로 쓴다 — `money.js`를 편 폴더에 같이 복사한다: 보기 카드는 국기 대신 동전 개수, 소품은 상표 없는 카드·영수증(`CARD`·`RECEIPT`), 정답 장면은 큰 금액 + 4등분 막대, 반전 장면은 쌓인 막대 + 점선 기준선.
- 썸네일: 제목 질문("카드 공제, 얼마부터?") + 보기 금액 알약 3개, 답 없음.

- 돈 그림(2026-10-31 사용자 요청 "돈처럼"): `money.js`의 `COIN`(금색 그라데이션·톱니 테두리·₩ 각인), `BILL`(연두 지폐·₩ 원·모서리 10000 — 실제 화폐 도안 아님), `MONEY(n)`(지폐 n장 + 금화, 보기 카드용), `JAR`(지폐가 삐죽 나온 금화 저금통). 노란 동그라미만 그린 동전은 쓰지 않는다.
